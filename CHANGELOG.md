## [0.4.0] - 2026-10-18

Desktop app 0.4.0 (Windows tray). Full visual + performance pass and a new brand. Report: [docs/ui/AUDIT-2026-10-18.md](docs/ui/AUDIT-2026-10-18.md), tracker [docs/ui/TRACKER.csv](docs/ui/TRACKER.csv).

### Added

- **Vatra brand** (`brand/`, pack 1.0.0): house-with-chimney mark with hearth flame and rising smoke in three optical sizes, ember palette on warm neutrals (DTCG tokens, WCAG gate 70 pairs / 0 failures), Inter + Inter Tight, logo motion (intro, thinking, success, error, hover, idle), every icon generated by script (favicon, PWA + maskable + mono badge, OG image, Tauri ico + MSIX logos, tray ok/warn/down/active for dark and light taskbars).
- Motion system: cold-start splash that morphs into the sidebar mark, list → detail shared-element morphs (instances, accounts, home device tile → sheet), tab indicators, skeleton → content crossfades, mark-as-loader NavProgress, command palette on cmdk with an open morph, empty-state illustrations, opt-in ambient warmth, opt-in kiosk tap sound/haptic. Reduced motion honoured everywhere (OS or in-app setting).
- Desktop: hidden window until first paint + splash → title-bar morph, light theme, kept-mounted pages, error boundaries, confirm dialog, focus ring, live tray state with taskbar-theme icons, `cold_start_ms` in desktop.log.
- Cloud browser-test harness on `dragos-devcloud` (`scripts/e2e-cloud/`): UI audit (92 routes × en/ro × light/dark × 360/1440/3440 + axe), Core Web Vitals, bundle sizes. `scripts/check-messages.mjs` validates every ICU message.

### Changed

- User-facing name is now Vatra (technical identifiers unchanged). Default accent is ember; the accent picker, surfaces, density and vibes remain.
- Upgraded motion 12 → 14 (LazyMotion + `motion/react-m`), lucide-react 0.475 → 1.59, sonner 1 → 2.
- Service worker: HTML is network-first (no stale authenticated pages), PNG icons and badge.

### Fixed

- axe serious violations 391 → 0 (contrast, scrollable regions, prohibited ARIA), clipped shadows 356 → 0, console errors 56 → 0 (invalid ICU message on /alerts, `/instances` 404), RO overflow at 360 px.
- Core Web Vitals 12/16 → 16/16 passing (mobile LCP on /settings, /sign-in, /monitoring, /activity was 3.5–4.5 s because content started at opacity 0 until hydration).
- First-load JS: `/` 707 → 466 KiB, `/topology` 669 → ≈ 461 KiB (three.js, recharts, xterm loaded on demand).
- Desktop idle CPU 1.32 % → 0.52 % of a core (one task query per minute while hidden), notifications stream reconnects on a stalled connection.

## [0.3.1] - 2026-10-17

Desktop app 0.3.2 (Windows tray). The Android app was not re-released: the change is in the `#[cfg(desktop)]` agent module, so the phone and the Pi keep 0.3.1 (versionCode 3001).

### Fixed

- The PC agent heartbeat (`vmui/pc/state`, every 15 s) no longer waits on HyperHDR. It used to log in to all five HyperHDR instances before each publish (~15 s per login, 2+ minutes per beat), so the Pi saw the PC offline for ~2 of every ~4 minutes and raised a "PC stopped responding" card about 15 times an hour. Instance info is now refreshed every 30 s on a separate thread.

### Changed

- `scripts/android-release.ps1` builds with JDK 21 whatever `JAVA_HOME` says (the Android Studio JBR is JDK 25, which AGP 8.11 / Kotlin 1.9 cannot build with). It uses `VMUI_JAVA_HOME`, then `JAVA_HOME`, then an installed Microsoft / Temurin JDK 21, and fails early otherwise. New `-NoPublish` switch: build and check the APK without uploading it to the Pi.

## [0.3.0] - 2026-10-16

Android / desktop app 0.3.1 (versionCode 3001).

### Fixed

- Notifications no longer pile up on the phone: the Android app keys a tagged card's notification (and its PendingIntents) on the tag, so a new card with the same tag replaces the old one; a server-side dismiss (`dismiss` / `dismissByTag`) now sends an FCM `type=dismiss` message that cancels it (fail-open). The "PC stopped responding" watcher fires only after 2 consecutive offline samples (~2 min), so sleep/wake flaps no longer alert.

### Security

- CI: lint, typecheck and tests through the shared `dragos-catalin/workflows` node-ci, plus a gitleaks + osv-scanner gate (full history weekly) and Renovate (`dragos-catalin/renovate-config`).
- Patched vulnerable dependencies the new gate found: next 16.3.8, nodemailer 10, drizzle-orm 0.45.3 / drizzle-kit 0.31, nanoid, ws, vitest 4.1.11; transitive pins in `pnpm-workspace.yaml` `overrides` (shell-quote, grpc-js, form-data, protobufjs, brace-expansion, js-yaml, postcss, browserslist, fflate, uuid). `braces` has no fixed release yet: documented in `osv-scanner.toml` until 2026-11-05.
- Desktop: `rumqttc` without default features (plain TCP MQTT only) drops the vulnerable `rustls-webpki` 0.102 (GHSA-82j2-j2ch-gfr8).
- `packageManager` pnpm 12.3.4, `engines.node >=24`, `.nvmrc` 24. Removed the `experimental.viewTransition` flag that Next 16.3 dropped (view transitions need no config).

### Added

- `POST /api/hooks/contact` (V3-30): dragoscatalin.ro contact form → notification kind `contact` (FCM, desktop toast, Android, HA Companion fallback, en + ro). HMAC-SHA256 over `${x-dc-timestamp}.${rawBody}` with `CONTACT_HOOK_SECRET` (503 when unset), ±300 s skew, nonce + signature replay table `contact_hook_nonces`, 10/min per source, zod-validated body, 280-char preview, message body never logged. HA bus event `vmui_notify` + optional automation `contact_flash` (`pi/ha-packages/vmui_contact.yaml`).
- Tailscale Funnel on homepi for `/hooks/contact` only (V3-31): `tag:funnel-hooks` + `funnel` nodeAttr in `infra/tailscale-home-acl.hujson`; runbook in `docs/fleet.md`.

## [0.2.0] - 2026-10-05

### Added

- MCP stream-lighting tools for TikSee and codai agents (WS21-01): `scene_list`, `scene_set` (curated scenes `party`, `calm`, `red_alert`, `gift_gold`, `rainbow`, `blackout_flash`, `default` with automatic restore) and `flash_color` (rgb or colour name, 1-5 flashes). Catalogue `STREAM_SCENES` in `src/lib/home/catalog.ts`.
- Home Assistant package `pi/ha-packages/vmui_stream.yaml`: `stream_scene_*` (mode: restart, newest wins) snapshot the RGB bulbs into `scene.stream_before` and restore them after the duration; strips go through HyperHDR priority 30 with self-expiry; `stream_flash` builds on `notify_flash`.
- Effect limiter for light effects (WS21-02, `src/lib/mcp/effect-limiter.ts`): per-key per-effect cooldown (flash 1.5 s, scene 10 s; `VMUI_EFFECT_COOLDOWN_{FLASH,SCENE}_MS`), burst merging (last call wins, one trailing run), `idempotencyKey` dedupe for 60 s. A limited call answers a non-error result `{ ok: true, limited: true, retryAfterMs, queued: true }`.
- API key scope preset `stream` (WS21-03): the eight stream tools, the RGB room lights as entity allow-list and the stream scripts; available in Settings → API keys and via `node scripts/mint-api-key.mjs <name> operator --preset stream`.

### Changed

- API key authentication looks a key up by `api_keys.lookup_id` (SHA-256 prefix of the token) and runs scrypt once, instead of against every non-revoked key. Keys minted before this release are found by the old scan once and backfilled.
- `scripts/mint-api-key.mjs` stores the lookup id and accepts `--preset stream` and `--rate`.
