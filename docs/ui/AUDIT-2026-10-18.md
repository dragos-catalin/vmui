# Vatra (vmui) — UI, brand and performance audit · 2026-10-18

Scope: every user-facing surface of the repo — web app (Next.js 16, 92 routes incl. the paired kiosk), PWA, desktop app (Tauri 2: Casă, Lumini, Dispozitive, Ambilight, Ecrane, Notificări, PC, Sistem, Setări, tray, control window), shared primitives, charts, LogViewer, sidebar/context rail, NavProgress, appearance system. One row per finding in [TRACKER.csv](TRACKER.csv) (id, severity, file:line, fix, status, evidence, VERIFIED/EXPECTED).

## Method

| Step | How | Where the evidence lives |
|---|---|---|
| Code audit | 4 read-only parallel audits (shell/primitives, home+kiosk+settings+auth, VM control plane, desktop) — 189 findings with file:line | `.copilot-tmp/uipass/audit-*.md` (scratch), consolidated in TRACKER.csv |
| Browser audit | **Cloud only** (owner rule): ephemeral GCE spot VM in `dragos-devcloud` (image family `vmui-e2e-runner`, bucket `vmui-e2e-runs-dragos-devcloud`, SA `vmui-e2e-runner`) builds the app, seeds a throwaway admin, runs `tests/e2e/ui-audit.spec.ts`: 92 routes × en/ro × light/dark × 360/1440/3440 = 1104 page loads; per page overflow, clipped text, text overlap, clipped box-shadows, console/page/hydration errors, axe WCAG 2.2 AA (360 + 1440), full-page screenshot | `scripts/e2e-cloud/`, results in `.copilot-tmp/e2e-cloud/<run>/test-results/ui-audit/` |
| CWV | `tests/e2e/cwv.mjs` in the same VM: LCP/CLS/FCP/TTFB + INP from real interactions, mobile profile (390×844, 4× CPU, Slow 4G) and desktop, median of 3, 8 main routes | `…/test-results/cwv/summary.json` |
| Bundles | `tests/e2e/bundles.mjs` first-load JS (gzip) per route from the Next build manifests | `…/test-results/bundles/summary.json` |
| Desktop | UIA tree + window screenshots of the rebuilt exe (dark + light), cold start (launch → visible window, plus the app's own `cold_start_ms` log line), idle RAM/CPU over 90 s with `--hidden` | `.copilot-tmp/uipass/desk-*-{before,after}.txt` |
| Design review | design-critic pass on cloud screenshots before/after (score /60) | this document § Design |

Lighthouse (`tests/e2e/lighthouse.mjs`) was attempted first and failed on every route with `net::ERR_ABORTED` (the app's long-lived SSE streams never let it reach network-idle, even with blocked URL patterns); CWV are therefore measured with Playwright + PerformanceObserver, the same metrics web-vitals reports.

Why some mobile LCPs went up while all now pass: before, pages without a big hero painted a small text block early (≈ 0.9 s) and four routes painted their main content only after hydration (opacity-0 entrance animations → 3.5–4.5 s). After: the self-hosted Inter/Inter Tight fonts (`font-display: swap`, latin + latin-ext) make the LCP text re-render once the woff2 arrives on Slow 4G (≈ 2.0 s, FCP stays ≈ 0.69 s), and no route waits for hydration any more. An intermediate run showed the splash/opacity regression at 3.2 s; it was fixed by making the splash a CSS-timed overlay (never hides content) and loading Motion's feature bundle asynchronously.

## Design review

design-critic on cloud screenshots: before ≈ 31/60, first after-pass **41/60** (brand 8, hierarchy 6, spacing 6, RO fit 6, light/dark 8, ultrawide 5). All its P1s were then fixed (kiosk palette + kiosk now audited with a throwaway token, mobile truncation on /home and /settings, floor-plan labels → legend under 640 px, nested empty states → `EmptyState fill/bare`, heading tracking, empty-page measure at 3440, CTA duplication, primary glow only on hearth surfaces).

## Brand

Brand pack 1.0.0 in [brand/](../../brand/BRAND.md): name **Vatra** (technical identifiers stay `vmui`), house-with-chimney mark with hearth flame and rising smoke (three optical sizes, keyline construction), ember primary h48 on warm neutrals, indigo secondary, amber = lit/on only, Inter + Inter Tight, logo motion set (intro, thinking, success, error, hover/press, idle, splash→UI morph) generated from one source, DTCG 2025.10 tokens, WCAG gate (70 pairs, 0 failures), every icon exported by script (favicon ico/svg, apple 180, PWA 192/512 + maskable + mono badge, OG 1200×630, Tauri ico 9 sizes + MSIX logos, tray ok/warn/down/active × dark/light × 16–48 px).

## Not done (stated, with reason)

- DK-30 (page list duplicated in Rust and TS) — needs codegen, low value.
- DK-35 — the audit itself rated it fine.
- DK-42 (desktop auto-update) — needs a new plugin and release infrastructure.
- SH-17 — shortcuts are ignored inside editable/ARIA widgets; a separate on/off setting was not added.
- Multi-size tray `.ico` — needs the `image-ico` Tauri feature in `Cargo.toml` (which has another agent's uncommitted edit); the tray uses the 32 px PNGs per state × taskbar theme.
- Lighthouse scores — see Method; CWV measured with Playwright instead.
